# OSNet-AIN 权重许可与来源证据

本目录保存作者官方 Hugging Face 模型仓库在固定 revision 的模型卡和 API 快照。模型卡明确标注 MIT，并说明该仓库提供训练好的 OSNet 行人重识别权重；本次许可判断并非从 Torchreid 架构代码的 MIT 外推。

具体文件、来源 URL、SHA256、模型契约和边界见 [evidence.json](evidence.json)。原始权重由 Git LFS 指针校验，导出 ONNX 身份独立记录。

分发时保留模型卡及 MIT 版权和许可声明，项目 Apache-2.0 不覆盖或替换上游 MIT。训练数据 MSMT17 不在本仓分发，本证据不代表训练数据完全开放、商用部署保证或模型准确率证明。
